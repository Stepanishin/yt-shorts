# План: автонарезки русских стримеров для TikTok / Instagram

Цель: автоматически делать вертикальные нарезки популярных моментов стримов,
публиковать в TikTok/Instagram и монетизировать через мидролы Playerok UGC
(700 ₽ за 100K просмотров, ролики от 50K просмотров).

## Принципы

- Отдельный модуль `lib/clips/`, не трогаем испанский news-пайплайн и прод-шедулер.
- Сначала CLI-скрипт и ручная публикация, автоматизация после первых результатов.
- Только стримеры, которые разрешают нарезки (список в `lib/clips/config.ts`).
- Ролик должен быть «преобразованным»: вертикаль, субтитры, заголовок.

## Фаза 1: MVP (CLI, ручная публикация)

1. **Источник: Twitch Clips API** (Helix `GET /clips`). Клипы, которые сделали зрители,
   отсортированы по просмотрам: это уже отбор лучших моментов людьми. Стримы целиком не пишем.
   - App access token через client credentials (`TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`).
   - Окно: последние 24-48 часов, минимум просмотров клипа, длительность 8-60 сек.
2. **Дедупликация**: коллекция MongoDB `stream_clips` (clipId уникальный), статусы
   `downloaded → rendered → posted / failed`.
3. **Скачивание**: `yt-dlp`. Порядок поиска: `YTDLP_PATH`, затем PATH, затем автоскачивание
   официального standalone-бинарника в `~/.cache/yt-dlp` (обновляется раз в неделю).
4. **Транскрипция**: OpenAI Whisper (`language: ru`, пословные таймкоды).
   - **Модерация**: 6 кадров + транскрипт через `omni-moderation-latest`; 18+, жесть и селфхарм пропускаем.
   - **Выбор отрезка** (`lib/clips/trim.ts`):
     - клип > 20 сек: LLM по транскрипту выбирает кусок 7-20 сек (завязка + панчлайн), границы по словам;
     - иначе или если LLM вернул keep_full: подрезка тишины до первого и после последнего слова.
5. **Рендер 1080x1920** (ffmpeg), раскладка определяется по каждому клипу (`lib/clips/facecam.ts`):
   - vision LLM по кадру с сеткой: вебка-оверлей / камера на весь экран / нет вебки;
   - второй проход по увеличенному фрагменту + уточнение границ по прямым краям рамки + центр лица;
   - вебка: сверху 1080x768 (кроп вокруг лица), игра снизу, субтитры на стыке;
   - камера на весь экран: кроп 9:16 вокруг человека; нет вебки: размытый фон + видео по центру;
   - мат в субтитрах и тексте поста заменяется звёздочками (`lib/clips/censor.ts`), звук не трогаем;
   - субтитры ASS, крупные, по 2-4 слова, поверх нижней трети.
6. **Мидрол Playerok** (опционально, `PLAYEROK_MIDROLL_PATH`), по правилам программы:
   - ролик ≤ 20 сек: в любой точке, кроме последних 3 сек (ставим на ~40% длины);
   - ролик > 20 сек: между 10-й и 20-й секундой (ставим на 10-й);
   - на время мидрола исходное видео на стоп-кадре, исходный звук на паузе;
   - мидрол виден целиком, без обрезки и затемнения.
7. **Заголовок и хэштеги**: LLM, на русском, без кликбейта-лжи.
8. **Выход**: `output/clips/<date>/<clipId>.mp4` + `.txt` с заголовком/описанием/хэштегами.
9. **CLI**: `npx tsx scripts/clips-run.ts [--streamer login] [--limit N] [--dry-run]`.

Критерий успеха фазы (2-4 недели): доля роликов с 50K+ просмотров в TikTok.

## Фаза 2: лучший отбор моментов

Сделано (`lib/clips/chat.ts`, `moments.ts`, `vod.ts`, `scripts/chat-collect.ts`, `scripts/moments-run.ts`):
- сборщик чата: анонимный IRC, 5-секундные счётчики (сообщения, уникальные люди, смех, шок) в `stream_chat_buckets` (TTL 14 дней);
- всплеск: 15 сек, в 2.5+ раза выше медианы за 10 мин, минимум 8% смеха/шока, 5 мин истории;
- вырезка из VOD: 30 сек до пика чата и 10 после, LLM с подсказкой о пике выбирает 7-20 сек.


- Анализ чата по записи (VOD chat replay): сообщения в минуту и частота эмоутов (KEKW, LUL…),
  пики → окна для нарезки, даже если зрители не сделали клип.
- Скоринг клипов: просмотры клипа / средние просмотры стримера, свежесть, длина.

## Фаза 3: публикация

- Instagram Reels через Graph API (нужен Business-аккаунт).
- TikTok Content Posting API (нужен аудит приложения; до аудита только приватные посты,
  поэтому до аудита публикация полуручная).
- Встраивание в `lib/scheduler.ts` с отдельным интервалом, прогрев аккаунтов: 1-3 ролика в день.
